# 承認済みの申請を取り下げる

承認された休暇申請や残業申請を無かったことにするには、「取り下げ」の手続きが必要です。承認前の申請を消す「取り消し」とは手順が異なります。

## 取り下げを申請する

本人が「取り下げ申請」を出し、承認者が承認すると取り下げが完了します。

1. 「申請」>「申請一覧」を開きます
2. 状態が「承認済み」の申請を選びます
3. 「取り下げを申請」を押します
4. 取り下げの理由を入力し、「申請する」を押します

承認者が取り下げ申請を承認すると、元の申請は無効になり、勤怠から取り除かれます。承認されるまでは元の申請が有効なままです。

## 取り下げできないケース

- 月次締めが完了した月の申請は取り下げられません。管理者に依頼してください
