# 打刻を修正する

打刻の忘れや時刻の間違いは、本人が「打刻修正申請」を出し、承認者が承認することで修正されます。打刻した時刻を本人が直接書き換えることはできません。

## 打刻修正申請を出す

1. 「勤怠」>「日次一覧」を開きます
2. 修正したい日の行にある「修正を申請」を押します
3. 正しい出勤時刻・退勤時刻・休憩時間を入力します
4. 修正理由を入力します（必須）
5. 「申請する」を押します

申請が承認されるまでは、元の打刻がそのまま有効です。承認されると、日次一覧の時刻が申請内容に置き換わります。

## 申請を出したあとに内容を直したいとき

承認前であれば、申請を取り消して出し直してください。手順は「申請を取り消す（承認前）」を参照してください。

## 修正できないケース

- 月次締めが完了した月の打刻は、本人からは修正申請を出せません。管理者に依頼してください（「月次締めと締め後の修正」を参照）
- 未来の日付に対しては修正申請を出せません
