# 通知を設定する

申請や承認に関する通知は、メールとスマホアプリのプッシュ通知で受け取れます。

## 通知の種類

| 通知 | 受け取る人 |
|---|---|
| 申請が届いた | 承認者 |
| 申請が承認された | 申請者 |
| 申請が差し戻された | 申請者 |
| 打刻忘れの可能性 | 本人 |
| 許可範囲外からの打刻 | 管理者（プレミアムプランのみ） |

## 通知を変更する

1. 画面右上のアカウントメニューから「通知設定」を開きます
2. 通知ごとに、メールとプッシュ通知のオン・オフを切り替えます
3. 「保存」を押します

## 打刻忘れの通知

退勤の打刻が無いまま所定の終業時刻から 2 時間が経過すると、本人に通知が届きます。通知の時間は変更できません。
