# 申請を取り消す（承認前）

まだ承認されていない申請（休暇申請、打刻修正申請、残業申請）は、本人がその場で取り消せます。

## 手順

1. 「申請」>「申請一覧」を開きます
2. 状態が「申請中」の申請を選びます
3. 「取り消す」を押します
4. 確認ダイアログで「取り消す」を押します

取り消した申請はすぐに無効になります。承認者への通知は送られません。取り消したあとに改めて申請する場合は、新しく申請を出し直してください。

## 承認済みの申請を取り消したいとき

すでに承認された申請には「取り消す」ボタンが表示されません。承認済みの申請を無かったことにするには、取り下げの手続きが必要です。「承認済みの申請を取り下げる」を参照してください。
