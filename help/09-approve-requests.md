# 承認者向け：申請を承認する・差し戻す

承認者に設定されているユーザーは、部下から届いた申請を承認または差し戻しできます。

## 申請を承認する

1. 「承認」>「承認待ち」を開きます
2. 申請を選び、内容を確認します
3. 「承認」を押します

複数の申請をまとめて承認するには、一覧でチェックを入れて「一括承認」を押します。

## 申請を差し戻す

1. 「承認」>「承認待ち」を開きます
2. 申請を選びます
3. 「差し戻し」を押します
4. 差し戻しの理由を入力します（必須）
5. 「差し戻す」を押します

差し戻された申請は申請者に通知され、申請者は内容を直して再申請できます。

## 承認者を変更する

承認者の設定は管理者のみ変更できます。「設定」>「組織」>「承認ルート」から変更してください。
