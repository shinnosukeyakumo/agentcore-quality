# 残業を申請する

残業申請は、スタンダードプランとプレミアムプランで利用できます。

## 残業申請を出す

1. 「申請」>「残業」を開きます
2. 残業する日付を選びます
3. 予定の終了時刻を入力します
4. 残業の理由を入力します
5. 「申請する」を押します

承認されると、承認された終了時刻までの労働時間が残業として集計されます。承認された時刻を超えて働いた分は、翌営業日までに再度申請してください。

## 事後申請

残業した翌日以降に申請することもできます。事後申請の場合は、手順 3 で実際の退勤時刻を入力してください。

## ライトプランをお使いの場合

ライトプランには残業申請の機能がありません。打刻された退勤時刻をもとに、所定労働時間を超えた分がそのまま残業として集計されます。残業を申請制にしたい場合は、スタンダードプラン以上への変更をご検討ください。
