# 休暇を申請する

有給休暇や特別休暇は、申請メニューから申請します。

## 休暇申請を出す

1. 「申請」>「休暇」を開きます
2. 休暇の種類（有給休暇、特別休暇など）を選びます
3. 日付を選びます。複数日をまとめて申請する場合は開始日と終了日を指定します
4. 全日か半日（午前・午後）かを選びます
5. 「申請する」を押します

承認者に通知が届き、承認されると勤怠に反映されます。承認されるまでは「申請中」として表示されます。

## 時間単位の休暇

時間単位の休暇申請は、スタンダードプランとプレミアムプランで利用できます。ライトプランでは全日と半日のみ申請できます。時間単位で取得する場合は、手順 4 で「時間単位」を選び、開始時刻と終了時刻を入力します。

## 残日数を確認する

有給休暇の残日数は、「申請」>「休暇」画面の上部に表示されます。
