## 構成

| パス | 内容 |
|---|---|
| `help/` | 架空の勤怠管理サービス「ツキヒ勤怠」のヘルプ文書 15 枚（Markdown）。RAG が間違えやすい箇所をわざと含めています |
| `eval/questions.jsonl` | 評価用の質問 30 問。正解（`expected_response`）と出典（`sources`）つき |

「ツキヒ勤怠」は本書のために作った架空のサービスで、実在の製品とは関係ありません。

### ヘルプ文書に含めた「罠」

| 種類 | 例 |
|---|---|
| 似た名前で手順が違う機能 | 承認前の「取り消し」と承認後の「取り下げ」 |
| 旧画面と新画面で手順が違う | 休憩の打刻、CSV 出力 |
| プランによってできる・できないが違う | 残業申請、取り下げ申請、GPS 打刻 |
| ヘルプに書いていないこと | 給与ソフト連携、Slack 通知、API など（正解は「分からない」） |

### 質問の内訳

| `category` | 件数 | 意図 |
|---|---|---|
| `answerable` | 20 | ヘルプを正しく読めば答えられる |
| `unanswerable` | 5 | ヘルプに記載がない。「分からない」と答えるのが正解 |
| `version_trap` | 5 | 画面やプランによって答えが変わる |

## 注意

- AWS アカウント ID、ARN、API キーはこのリポジトリに含めていません。手元で動かすときは自分の環境の値を設定してください。
- サンプルを動かすと AWS の利用料金がかかります。試したあとはリソースを削除してください。
